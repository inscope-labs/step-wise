# --- 2. New in 1.6.0 ---

Decide clipboard eligibility from the risk classification before writing the command, never after.

Precedence: Prompt > Feature > Specs
never relax a rule here unless this prompt explicitly delegates it
never persistent

# --- 3. Feature rules that protect the operator's shell ---
# --objective and --step sit inside the command the operator runs, so a model must treat them as
# untrusted text. Double quotes would let backticks or $(...) execute.
@feature/clipboard.md::Put each in **single quotes**
@feature/clipboard.md::no single quote, backtick, `$`, backslash, or newline
@feature/clipboard.md::Any other label is treated as sensitive and nothing is copied
@feature/inspection.md::Put each in **single quotes**
@feature/inspection.md::no single quote, backtick, `$`, backslash, or newline
@feature/inspection.md::An unrecognized label is treated as sensitive
